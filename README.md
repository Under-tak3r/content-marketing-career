# Content Marketing Career｜内容营销实战与求职

面向互联网与外企快消初级内容营销、品牌策划和活动运营岗位的 AI Skill。将岗位要求转成可交付、可解释、可验证的作品证据。

**一个入口，八个按需加载模块；支持交付、训练、评审和面试四种模式。**

## 模块

| 模块 | 主要产物 |
|---|---|
| 用户与热点洞察 | 有出处的竞品观察、洞察卡、选题机会 |
| 卖点与品牌表达 | 产品事实到用户利益的证据链、信息屋 |
| 内容策略 | 一页策略、平台分工、选题日历 |
| 内容创作 | 小红书成稿、短视频分镜、公众号内容 |
| 活动与达人合作 | Campaign Brief、合作Brief、物料与执行表 |
| 数据与增长实验 | 指标口径、复盘与实验设计 |
| 外企快消专项 | 中英文Brief、消费者场景与本土化表达 |
| 求职与作品集 | JD能力映射、案例、简历与面试训练 |

## 使用

将本仓库下载并解压为 `content-marketing-career` 文件夹，放入支持本地技能的工具的技能目录。Codex 的个人技能目录通常为 `~/.codex/skills/`；若配置了 `CODEX_HOME`，使用其下的 `skills/`。保留 `SKILL.md`、`references/`、`assets/` 和 `agents/` 的相对结构。

调用示例：

> 使用 $content-marketing-career，进入训练模式。根据我提供的JD与经历，选择一个内容营销作品集主项目，列出能力证据，再给第一项练习。

> 使用 $content-marketing-career，进入交付模式。根据我提供的产品资料，为通勤人群设计两周内容计划，交付一页策略、两篇完整图文和一条30秒分镜。未知产品主张标为待验证。

> 使用 $content-marketing-career，评审我的作品集。区分真实项目、自主提案与模拟实验，指出三个最影响说服力的问题，并修改关键部分。

## 工作原则

- 事实、推断、假设与模拟数据明确区分；用户原话和产品主张可回查。
- 未上线的提案呈现验证计划，不编造增长成绩。
- 内容营销包含策略判断，训练不仅是生成文案。
- 训练模式保留用户初稿、反馈与修改理由，突出本人决策。
- 仅按任务加载所需模块，不自动发布内容、外联或付费投放。

## 模拟数据示例

以下仅为教学模拟，不是业绩：A有1000次曝光、100次点击、5笔订单、广告费200；B有2000次曝光、100次点击、10笔订单、广告费300。

参考输出：A/B点击率为10%/5%，点击到订单转化率为5%/10%，每单广告成本为40/30；总体点击率为200/3000≈6.67%。缺订单金额时不能计算ROAS，观察差异不能直接证明创意因果效果。

## 文件结构

- `SKILL.md`：入口、模块选择与共同约束。
- `references/`：八个工作模块及训练方式。
- `assets/`：项目上下文与作品集案例模板。
- `agents/openai.yaml`：技能名称与默认调用提示。

## 能力边界与安全

本仓库仅包含Markdown说明、模板与技能元数据，没有可执行脚本、第三方依赖、API密钥或自动运行工作流。使用本技能本身无需在仓库填写密钥。

近期研究需要宿主工具具备实际搜索或平台访问能力；本仓库没有附带平台抓取器。图片、成片和演示文件制作需要对应工具。工作流指令的存在不保证宿主会正确执行，真实效果需实际验证。

请勿将个人简历、客户资料、真实账号凭据或未获准公开的数据提交到公开仓库。项目资料应保存在独立的私人工作目录。
