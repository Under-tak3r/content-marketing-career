# 案例标题

**项目性质：** 真实项目 / 自主提案 / 公开案例分析 / 模拟实验（选择真实适用项）
**时间与个人角色：**
**一句话概括：** 面向谁、处理什么问题、做了什么。

## 问题与约束
业务目标、受众行动、资源与负责边界。

## 证据与洞察
列来源/日期或材料定位；写出从观察到洞察的推理和限制。

## 关键取舍
备选方向、选择理由、放弃什么、本人贡献。

## 策略与实际成品
展示成稿/分镜/Brief，并解释如何回应洞察。

## 执行与结果
已完成范围；仅写有依据的结果。未上线项目改为“验证计划”，模拟数据显式标明。

## 复盘
什么证据支持/反驳判断、修改了什么、下一步如何检验。

## 资料与贡献说明
资料来源、协作分工、AI使用范围及本人核实/修改内容。
